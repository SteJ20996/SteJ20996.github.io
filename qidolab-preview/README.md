# Qidolab playful visual preview

Preview address: https://stephenjia.com/qidolab-preview/

This separate preview uses a mist-lavender background (#f3f1f7), deep-teal game boards, mint action buttons and restrained coral accents. Lavender marks optional extra steps; gold stays with earned crowns and completed orbit titles. It tests learner-facing playful copy in Chinese, English and Spanish, and gold orbit titles after the original, extra step and extreme challenge are all completed. Viewing an answer keeps the crown hollow. Viewing an answer without solving the extreme does not complete it or turn a title gold.

The original game rules, questions and answer checks are retained. The appearance preview control can temporarily show one gold title, a complete gold ring, or a gold title with a hollow crown. These display presets do not write solved-game records. Normal play continues to save progress in the browser.

All runtime assets are local to this folder. The existing /qidolab/ playtest remains separate while this visual version is reviewed.
